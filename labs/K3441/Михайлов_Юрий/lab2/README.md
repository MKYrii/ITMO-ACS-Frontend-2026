# SpbRent — лабораторная работа 2

Статический интерфейс запускайте через Live Server/любой локальный веб-сервер. API работает отдельно на `http://localhost:3000`.

## Запуск API

```bash
npm install
npm run api
```

Используется JSON Server вместе с `json-server-auth`. Регистрация и вход идут через `/register` и `/login`, защищённые записи используют Bearer-токен. Приложение также сохраняет текущий токен и пользователя в localStorage.

Коллекции базы: `users`, `messages`, `requests`. При регистрации создайте аккаунт, затем войдите в него; тестового пользователя можно добавить через форму регистрации.
